# Flint Kart

Flint Kart is an arcade kart racer built on [Flint](https://github.com/chrischaps/Flint), my own Rust game engine. Six karts line up behind a checkered line and race three laps; you hop into a drift, hold it through the corner, and let go for a boost that grows with the sparks. It began as a proving ground for the engine, the first place its physics, AI, audio, particles, scripting and UI all had to work together at speed, and it grew into a game with four tracks, items, and every sound generated by code.

**Project page:** [chaps.dev/projects/flint-kart](https://chaps.dev/projects/flint-kart/) has screenshots of a race and more on the tracks.

**Play it in the browser:** [play.chaps.dev/?game=kart](https://play.chaps.dev/?game=kart), with keys, a gamepad or a phone held sideways.

## Running it

You need Windows and a stable Rust toolchain. The engine is included at `engine/`, so there is nothing else to fetch.

```bat
build.bat        :: build the engine and player (release)
play.bat         :: start at the main menu
play.bat scenes\the_crossroads.scene.toml   :: or go straight to a track
render.bat       :: render snapshots of Oval Plus without opening a window
```

There are shortcuts for single tracks too: `play_mountain.bat` (Mountain Switchback) and `play_bay.bat` (Lighthouse Bay). `edit_track.bat` opens Oval Plus in Flint's scene viewer.

The asset generators in `tools/` are Python; the audio ones need numpy, scipy and soundfile.

## How it's built

- **Tracks** are splines with the road, walls and verges swept along them: Oval Plus, Mountain Switchback, The Crossroads (which forks around a shortcut) and Lighthouse Bay. Each track's scenery comes from a recipe in `tracks/`, built by `tools/dress_track.py`.
- **Driving is script.** `scripts/kart_controller.rhai` holds the kart physics; `ai_driver.rhai`, `race_manager.rhai`, `item_manager.rhai`, `chase_camera.rhai` and `hud.rhai` do the rest.
- **Everything you hear is generated** by `tools/generate_audio.py`, `generate_item_audio.py` and `generate_music.py`.
- `scenes/`, `prefabs/`, `schemas/` and `ui/` are TOML; models are GLB, most of them generated by the Python tools.
- `engine/` is the Flint engine as a git subtree.
